# Integrated Underlying-Price Backtest — Corrected Scope

This report previously described stock-return proxy strategies using options
terminology. That presentation was incorrect and has been retired.

The underlying v4 research may be reviewed as exploratory equity-signal work,
but it is not evidence for cash-secured puts, covered calls, volatility-risk
premium capture, or any other option-contract strategy. It lacks historical
option bid/ask, premium accounting, exercise and assignment, dividends, OCC
adjustments, and broker collateral rules.

No option-performance ranking from the retired report remains valid. Refer to
`data/OPTIONS_RESEARCH_STATUS.json` for current options status and to
`data/backtest_results/integrated_backtest_latest.json` only for the underlying
proxy outputs, with this scope limitation attached.
