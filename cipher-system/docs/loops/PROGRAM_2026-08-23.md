# Cipher improvement loop program — 2026-08-23

This is an evidence-driven, panel-by-panel program. It is **not** a whole-repo restyle, not a live-trading expansion, and not 100 cosmetic tweaks.

## Operating rules (every loop)

1. Read this file and `LEDGER.md`. Execute the next `queued` loop only.
2. Write a loop plan to `docs/loops/NNN-<slug>.md` **before** editing code. The plan must name files, behavior to preserve, anti-goals, and runnable checks.
3. Ponytail: one defect family per loop. Reuse tokens in `DESIGN.md` and patterns in `SkewMap.tsx` / `OptionsTerminal.tsx`. No new dependencies.
4. Safety: no live broker host, no browser/core order route, no secret printing, no runtime DB rewrite, no `cipher-alpaca-agent` work.
5. Data: missing stays unknown. GEX remains a public-OI heuristic.
6. Verify before claiming: focused Node tests always; `npm run lint` + `typecheck` when TSX/CSS changed; `sync_web_build.sh` when guest-visible; hosted guest E2E every 5 completed UI loops or when `guestCatalog` / `PanelHost` changes.
7. Do **not** commit. Do **not** invent work when the next loop’s skip-if is true: mark `skipped` with reason.
8. Stop the wake loop if 100 complete, if the next item is nonsense, or if the user says stop.
