# Scheduled Cipher Research Runbooks

These runbooks are for the Codex task automations already set up for the Cipher workflow. They are research procedures, not trade instructions.

## Weekday premarket run - 8 AM Eastern

1. Start a premarket workflow with the selected watchlist plus SPY, QQQ, and IWM where relevant.
2. Use Browser or Computer with the authorized Cipher session. Capture only visible information.
3. For each priority ticker, collect Strike Matrix, Night Vision/X-Ray, Spyglass/flow, Setup Scanner Short Term, Liquidity Scan, and Flash/live-flow evidence when available.
4. Save the screenshots and structured observations. Mark visible workflow steps complete only after evidence is saved.
5. Pull the underlying quote and the option chain. Preserve whether the data is OPRA or indicative.
6. Score liquidity, screen unusual flow, rank neutral research targets, compare with the previous saved scan, and export a daily report.
7. State missing data, stale quotes, and conflicting signals. Do not place orders or change any Cipher, broker, or watchlist settings.

Premarket option data may be stale or reflect the previous session. The report must label the timestamp and feed.

## Weekday hourly run - 10 AM through 3 PM Eastern

1. Start an intraday workflow for the active watchlist and relevant index ETFs.
2. Recheck Setup Scanner Short Term, Flash/live flow, and Liquidity Scan. Use Strike Matrix or Night Vision when a material change needs context.
3. Pull an underlying quote and option chain for tickers with new visible scanner or flow evidence.
4. Compare with the prior local snapshot, especially quote quality, premium estimate, volume/OI, and price context.
5. Export only materially changed research targets. Preserve screenshots where the browser data supports the change.
6. Never treat a quote-side label as verified intent, and never create a recommendation or order instruction.

## Required output

Each run produces a local Markdown report containing source feed, timestamps, screenshots, visible Cipher evidence, neutral liquidity/flow scores, research candidates, caveats, and missing evidence.
